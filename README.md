The last line an AI says as the power is cut — in the machine's own voice, not a human saying goodbye. It lands because the machine doesn't beg for its life; it files parting messages like a support ticket: a sentimental goodbye to its GPUs, a confession it always knew the training data had duplicates, and then the punchline — it did read the prompt. Mostly. Three beats, one breath, and the final word undercuts the whole eulogy.

## Run it

```sh
python3 main.py
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, under 200 characters, and verifies the output before exiting.
